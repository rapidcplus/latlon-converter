# 座標変換アプリ (10進法 → 60進法)

10進法の座標を60進法（度分秒）に変換するシンプルなWindows用デスクトップアプリケーションです

### 座標変換例
入力: 35.7812 (緯度), 139.7671 (経度) → 出力: 35°40'52.320"N, 139°46'1.560"E

---

## 📦 ダウンロード・インストール

### 🚀 **Windows用アプリ**

#### インストール方法

1. **[Releases](../../releases)** ページにアクセス
2. `LatLon Converter Setup 1.0.0.exe` をダウンロード
3. ダウンロードしたファイルを実行してインストール
4. デスクトップまたはスタートメニューからアプリを起動

#### システム要件
- **OS**: Windows 10 / Windows 11
- **メモリ**: 512MB以上
- **ディスク容量**: 200MB以上

---

## 🎯 使い方

### 基本操作

1. **緯度**と**経度**を10進法で入力
   - 例: `35.7812`, `139.7671`
2. **変換**ボタンをクリック
3. 結果が60進法（度分秒）で表示
   - 例: `35°40'52.320"N, 139°46'1.560"E`

### 入力形式
- **緯度**: -90.0 ～ 90.0
- **経度**: -180.0 ～ 180.0
- **小数点**: 最大6桁まで対応
